# Array Operations (JavaScript)

Three JavaScript functions that each take an array and perform one operation on it.

## Features
| Operation | Function type used |
|-----------|--------------------|
| Find the maximum number | Function declaration (`findMax`) |
| Sum of all elements | Arrow function (`calculateSum`) |
| Count of odd numbers | Anonymous function expression (`countOdd`) |

## Files
- `index.html` – page structure, links CSS and JS
- `style.css` – styling
- `script.js` – the functions and the test array
- `Readme.md` – this file

## How to run
1. Open `index.html` in a browser.
2. Press `F12` and open the **Console** tab.

## Sample output
Test array: `[4, 8, 2, 11, 6, 7, 10]`

```
Maximum number: 11
Sum of all elements: 48
Count of odd numbers: 2
```

Results are also shown on the page.
